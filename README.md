# 💊 Pharmacy Inventory Management System

A console-based Pharmacy Inventory Management System developed in C++ using Object-Oriented Programming (OOP) and file handling.

This project helps manage medicine inventory, suppliers, stock quantities, expiry dates, prescription orders, billing, and inventory reports through a simple menu-driven interface.

## 🚀 Features

- **Medicine Inventory:** View medicine IDs, names, suppliers, expiry dates, quantities, and prices.
- **Search Medicine:** Find a medicine using its ID.
- **Stock Management:** Restock medicines and update their quantities.
- **Price Management:** Update medicine unit prices.
- **Low-Stock Alerts:** Identify medicines below a specified stock threshold.
- **Expiry Reports:** Generate reports for expired medicines and medicines expiring today.
- **Prescription Processing:** Process orders from a text file and validate medicine availability.
- **Billing System:** Calculate subtotals, discounts, and grand totals.
- **Stock Valuation:** Identify the medicine with the highest total stock value.
- **Data Validation:** Reject invalid records and duplicate medicine IDs.
- **File Handling:** Read inventory and order data from text files and generate reports.

## 📁 Project Files

- `pharmacy_inventory.cpp` — Main C++ source code.
- `medicines.txt` — Medicine inventory input file.
- `orders.txt` — Prescription and order input file.
- `errors.txt` — Generated report of rejected inventory records.
- `expired.txt` — Generated expiry report.
- `bill.txt` — Generated billing report.

Note: The text data files must be provided separately if you want to run the program with sample data. The report files are generated by the program.

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE, such as VS Code or CLion.
3. Make sure a C++ compiler is installed.
4. Place the required input text files in the program's working directory.
5. Compile the source code.
6. Run the executable.
7. Enter the inventory filename and today's date when prompted.
8. Select an option from the pharmacy menu to manage medicines, process orders, or generate reports.

## 📄 Input File Formats

### Medicine Inventory — `medicines.txt`

Each line contains:

`ID Name SupplierName SupplierCity Day Month Year Quantity UnitPrice`

Example:

`101 Panadol ABCPharma Lahore 31 12 2027 100 25.50`

Names are stored as single words in the current file format.

### Prescription Orders — `orders.txt`

Each line contains:

`PrescriptionNumber MedicineID Quantity`

Example:

`1 101 2`

Each record represents a medicine requested under a prescription number.

## 🧾 Generated Reports

- `errors.txt` — Rejected inventory records and validation reasons.
- `expired.txt` — Expired medicines and medicines expiring on the specified current date.
- `bill.txt` — Processed order details, billing totals, discounts, and accepted/rejected order counts.

## 💰 Billing Rules

- Orders for medicines that are not found are rejected.
- Expired medicines are rejected.
- Invalid or unavailable quantities are rejected.
- A 10% discount is applied to a prescription subtotal when it exceeds Rs. 1,000.
